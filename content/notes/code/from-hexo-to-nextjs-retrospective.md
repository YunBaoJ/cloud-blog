## 一、 起点：大一春天的「云深不知归处」

翻开 GitHub 仓库中最早的提交历史，`YunBaoJ/yunbaoj.github.io` 诞生于 2023 年 4 月至 5 月，那正是我大一下学期的时光。

那时候的我，刚刚敲开计算机科学与软件工程的大门，怀揣着对未知的强烈好奇，希望能拥有一个属于自己的数字自留地。于是，在 GitHub Pages 上建立起了初代个人主页 —— **「云深不知归处 (Cloud’s blog)」**，并在主页留下了一句纯真而温柔的座右铭：

> *May the world be closely tied with you.*（愿世界与你紧密相连）

如今三年过去，当这间数字小屋升级为基于 **Next.js 16、React 19、TypeScript 与 Web Audio 掌机引擎** 构建的现代空间时，再次下载并回溯当年的代码仓库，不仅是一次有趣的技术考古，更是一场与初心久别重逢的对话。

---

## 二、 初代博客技术全景拆解 (2023)

初代博客的本质是一个典型的 **Jamstack 静态站点**，依托当时的 Node.js 生态与静态托管服务快速成型：

- **核心生成器**：`Hexo 6.3.0`（基于 Node.js 的静态博客框架）；
- **主题选型**：`Theme Shoka v0.2.5`（一款极具和风与极客美感的二次元主题，支持 Pjax 页面无刷新转场与 Algolia 搜索）；
- **托管方案**：`GitHub Pages`，通过 Git 本地推送生成的静态文件直接挂载根域名；
- **排版字体**：引入了 `Noto Serif SC`、`Noto Serif JP` 与等宽字体 `Inconsolata`；
- **多语言与 Feed**：原生配置了 `Atom.xml`、`RSS.xml` 与 `search.json` 搜索索引。

```text
+-------------------------------------------------------------+
|                   2023 初代静态博客架构                       |
+-------------------------------------------------------------+
|  内容层: 本地 Markdown 文档 (Linux 笔记 / Hello World)       |
|  引擎层: Hexo 6.3 静态编译器 + Theme Shoka 渲染模板           |
|  交互层: 基础 Pjax 局部刷新 + Valine / 静态搜索框             |
|  分发层: GitHub Pages (yunbaoj.github.io)                   |
+-------------------------------------------------------------+
```

在那个阶段，我的主要精力集中在**学习 Git 分支管理、了解静态生成（SSG）概念、配置主题 YAML 属性以及借助 CDN 引用外部资源**。它帮我跨过了从「只在本地写代码」到「向公网发布产品」的关键心理门槛。

## 四、 认知跃迁：从「套用模板」到「全栈自研」

对比三年前后的两个博客项目，最大的变化不仅在于代码语言或框架的版本号，而在于**对软件架构与工程控制权的认知跃迁**：

### 1. 从「配置消费者」转向「系统构建者」
- **过去**：阅读主题作者的 README，按说明修改 `_config.yml`。如果遇到主题不兼容或动画卡顿，只能望洋兴叹，受限于他人封装的边界；
- **现在**：全站从零写起。纯原生手写 CSS 3D Translation 滑轨、基于 GSAP 构建动画生命周期、自研 Web Audio API 程序化音频合成器、用 Canvas 绘制 60fps 动态贪吃蛇与华容道算法。每一行 CSS 与组件逻辑，都严格追溯自自己的产品意图。

### 2. 从「粗糙感知」转向「极致审美与工程规范」
- **过去**：为了好看盲目堆砌插件，背景图、看板娘、特效代码导致首屏加载臃肿不堪；
- **现在**：贯彻东方**侘寂美学（Wabi-Sabi）**与反模板化设计准则。执行**严格零 Emoji 规范**以杜绝轻浮的 AI 感，引入完整的色彩代币系统，并编写 14 项端到端自动化测试，追求工业级的高级质感。

## 五、 两代博客全方位工程对比

```text
+---------------------+-------------------------------+-----------------------------------+
| 评估维度             | 2023 初代 (yunbaoj.github.io) | 2026 现代小屋 (Kasumi Cottage)     |

| 核心框架             | Hexo 6.3.0                    | Next.js 16.3 (App Router)         |
| 编程语言             | 纯 HTML/JS/CSS (依赖生成器)   | 严格类型检查 TypeScript            |

| 声音体系             | 无                            | Web Audio 纯代码合成无损音效      |

| 质量保障             | 无测试，完全靠肉眼预览        | Node Test Runner 全量测试保障     |
```

## 六、 结语：致敬来时的每一步

计算机科学的魅力，就在于每一次积累都绝不浪费。

初代博客 `yunbaoj.github.io` 虽已定格在大一的夏天，但它见证了我敲下第一行 Bash 命令、第一次提交 Git Commit、第一次把自己的文字分享给互联网的激动心情。它像一块路标，忠实地记录了我从懵懂技术爱好者向专业工程师蜕变的起点。

**云深不知归处，而脚下的路已越走越宽广。**
