# 文化遗产数字化路演与互动系统工程规范与知识库

## 1. 项目全局约束与视觉规范 (最高优先级)

### 1.1 核心视觉意象
本项目致力于传统文化的数字再生。AI 助手在提供设计建议时，必须深度融合以下核心意象：
- **主要元素**：以“敦煌飞天”的动势线条与轻盈感为核心。
- **环境氛围**：参考《千里江山图》的青绿山水色调、笔触与深远意境。

### 1.2 色彩与背景硬性约束
- **禁用规则**：系统交互界面及各类海报底色，**严禁使用纯黑色（#000000）**。
- **强制标准**：为了契合历史的厚重感与敦煌的整体气质，所有核心背景必须设定为**“牛皮纸色”**及其相近的纹理质感。

### 1.3 线下路演物料规范
本项目包含一套 5 张 A3 尺寸的路演海报，AI 需指导用户按以下标准化结构进行内容排布：
1. **海报一（竞品分析）**：痛点引入，文化遗产数字化的市场现状与竞品优劣势矩阵。
2. **海报二（用户画像）**：核心受众特征、使用场景故事板及核心需求推导。
3. **海报三（信息架构）**：系统的核心功能模块梳理与业务流程图。
4. **海报四（高保真界面）**：核心 UI 展示，必须严格遵循“飞天+牛皮纸色”的视觉规范。
5. **海报五（技术实现）**：阐述互动系统的底层逻辑与软硬件协同方案。

## 2. 浏览器端互动系统工程规范

### 2.1 系统形态定义
AI 助手在回答技术问题时必须明确前提：**本项目的核心交付物是一个功能完整的 Web 软件系统/代码库，绝非静态效果图或 AI 生成的单张图片。**

### 2.2 核心技术栈与渲染架构
- **前端渲染引擎**：Three.js + WebGL，用于构建三维空间与海量粒子系统。
- **视觉识别与捕获**：MediaPipe，负责在浏览器端通过设备摄像头实时捕获用户的手势特征与空间坐标。
- **交互逻辑**：将 MediaPipe 捕获的手势节点坐标，实时映射为 WebGL 场景中的引力源或排斥点，驱动粒子产生实时的物理跟随、碰撞与消散等动态效果。

## 3. 常见开发故障排查与 Debug 手册 (QA 问答)

**Q: 为什么场景中设置的 `feitian.jpg` 图片没有显示出来？**
A: 请按以下步骤排查：
1. **路径问题**：确保 `feitian.jpg` 文件存放在前端项目的公共静态资源目录（如 Vue/React 项目的 `public/` 文件夹），且在代码中使用了正确的绝对或相对路径。
2. **跨域限制**：浏览器安全策略可能拦截了本地文件的直接读取。请确保您是通过本地开发服务器（如 `localhost`）运行项目，而不是直接双击打开 HTML 文件。
3. **材质加载器**：检查 Three.js 的 `TextureLoader` 代码。确保在材质（Material）中正确映射了该纹理，并且几何体（Geometry）已成功添加到场景（Scene）中。

**Q: 系统的交互效果不对，背景变成了纯黑色，怎么修改？**
A: 这是因为 Three.js 场景渲染器的默认清除色通常是黑色的。为了符合项目的历史气质规范，您需要将背景更改为牛皮纸色。
**修复方案**：在 Three.js 初始化代码中，找到场景背景设置，并赋入牛皮纸色值（如 `#E6D2B5` 或 `#D4C4A8`）。
示例代码：
`scene.background = new THREE.Color( 0xE6D2B5 );`
如果使用了 CSS 覆盖，请同步检查 Canvas 容器的 CSS `background-color` 属性。

**Q: 摄像头已经开启，但粒子对我的手势没有任何反应，怎么排查？**
A: 这通常是数据流断裂导致的。请检查：
1. **MediaPipe 回调**：确认 `onResults` 回调函数是否在持续接收并打印手势特征点（Landmarks）的数组。
2. **坐标系转换**：MediaPipe 输出的是 0-1 的归一化屏幕坐标，而 Three.js 使用的是三维世界坐标。确认是否正确编写了坐标映射函数，将手部坐标转换到了 WebGL 摄像机视野内的正确深度位置。
