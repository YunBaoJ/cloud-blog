# 近况页替换实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用自动汇总笔记与图集更新的 `/now` 页面替换本机留言板，并保持旧地址可用。

**Architecture:** `/now` 保持为服务端路由，直接读取 `getAllNotes()`、`GALLERY_PHOTOS` 与 `PLAYGROUND_ITEMS`。路由目录内的纯函数将笔记和图集归一化、排序并限制为八条，页面只负责展示；旧 `/guestbook` 通过服务端永久跳转迁移。

**Tech Stack:** Next.js 16.3 App Router、React 19、TypeScript、Tailwind CSS 4、Lucide React、Node 24 内置测试运行器。

## Global Constraints

- 保留既定的 Mossland Warm Light 视觉系统和全局背景层。
- 苔绿是唯一主要交互色，杏色只作为图集类型的辅助细节。
- 使用现有系统字体和 Lucide 图标，不新增依赖。
- `/now` 为服务端组件，不增加客户端状态或水合成本。
- 更新流最多展示八条；完整历史继续由 `/archive` 和 `/gallery` 承担。
- 不伪造游乐场更新时间、个人近况或站点指标。
- `<768px` 使用单栏，所有主要交互目标至少 `44px` 高。
- 兼容浅色、深色、键盘焦点和 `prefers-reduced-motion`。
- 避开现有未提交的 `src/app/notes/NotesClient.tsx`、`src/components/Hero.tsx` 和预览文件。

- [ ] **Step 4: 实现最小活动转换函数**

创建 `src/app/now/activity.ts`：

```ts
export interface ActivityNoteSource {
  id: string;
  title: string;
  summary: string;
  date: string;
}

export interface ActivityGallerySource {
  id: string;
  title: string;
  story: string;
  date: string;
  src: string;
  width: number;
  height: number;
}

export interface ActivityItem {
  id: string;
  kind: "note" | "gallery";
  title: string;
  summary: string;
  date: string;
  href: string;
  image?: {
    src: string;
    width: number;
    height: number;
    alt: string;
  };
}

export function buildActivityItems(
  notes: ActivityNoteSource[],
  photos: ActivityGallerySource[],
  limit = 8,
): ActivityItem[] {
  const noteItems: ActivityItem[] = notes.map((note) => ({
    id: `note-${note.id}`,
    kind: "note",
    title: note.title,
    summary: note.summary,
    date: note.date,
    href: `/notes/${note.id}`,
  }));

  const galleryItems: ActivityItem[] = photos.map((photo) => ({
    id: `gallery-${photo.id}`,
    kind: "gallery",
    title: photo.title,
    summary: photo.story,
    date: photo.date,
    href: "/gallery",
    image: {
      src: photo.src,
      width: photo.width,
      height: photo.height,
      alt: photo.title,
    },
  }));

  return [...noteItems, ...galleryItems]
    .sort((left, right) => right.date.localeCompare(left.date) || left.id.localeCompare(right.id))
    .slice(0, Math.max(0, limit));
}
```
