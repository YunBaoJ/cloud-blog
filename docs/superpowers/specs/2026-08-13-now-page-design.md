# 近况页设计规格

## 目标

将仅保存在访客本机、缺少共享价值的留言板替换为“近况”页。新页面帮助回访者快速了解数字小屋最近新增了什么，并为笔记、图集和游乐场提供统一但克制的入口。

## 范围

- 新增 `/now` 页面并将导航中的“留言板”改为“近况”。
- 自动汇总笔记与图集的最新内容，按日期倒序展示。
- 展示小屋当前可浏览的内容数量与最近更新时间。
- 在页面末尾提供游乐场入口，但不把没有更新时间的游戏伪装成最近更新。
- 保留 `/guestbook`，将旧地址跳转到 `/now`。
- 更新站点地图、README 和项目路线说明中的对应栏目。
- 删除不再使用的留言板客户端实现及其本地存储逻辑。

不在本次范围内：新增后端、评论系统、访问统计、订阅系统、内容管理后台，以及修改首页、笔记、图集或游乐场本身的布局。

## 信息架构

页面沿用内页的既定开场节奏：短标签、标题“近况”、一句说明、分隔线。主体分为三段：

1. **小屋状态**：最近更新时间，以及笔记、图集和游乐项目数量。
2. **最近发生**：笔记与图集组成的统一时间流。
3. **继续闲逛**：指向游乐场的单一入口，说明这里是长期开放的常驻房间。

“小屋状态”描述站点事实，不添加未经确认的个人状态、阅读计划或正在进行的项目。

## 布局与视觉

### 桌面端

使用不对称双栏布局。左栏较窄，在视口内保持可见，承载页面说明、最近更新时间和内容数量；右栏较宽，承载更新流。该结构让状态信息稳定，同时让内容记录成为主要阅读路径。

更新流不使用重复的大卡片。每条记录由日期、类型、标题、摘要和目标链接组成，以留白和单条底部分隔线建立节奏。图集记录可显示小幅自然比例缩略图；笔记记录以文字为主。首条记录获得更大的标题和间距，但不改变数据结构。

### 移动端

在小于 `768px` 时改为单栏。状态信息位于时间流之前，不使用粘性定位；缩略图位于文字下方或右侧受限区域，页面不得产生横向滚动。所有可点击目标至少为 `44px` 高。

### 视觉系统

- 沿用现有苔绿暖纸色令牌，不添加新的饱和色。
- 苔绿表示主要交互，杏色只用于区分图集类型的小细节。
- 使用现有系统字体和 Lucide 图标，不新增字体或图标依赖。
- 内容表面采用轻微透明纸张质感，主要分组依赖留白与细分隔线，避免通用卡片堆叠。
- 圆角遵循现有规则：内容表面使用 `16-24px`，交互控件使用胶囊形。
- 深色模式保持深绿表面、暖白文字和同一语义层级。

## 数据与组件

`/now` 的路由页面保持为服务端组件。它从既有数据源读取内容：

- 笔记来自 `src/lib/notes.ts`。
- 图集来自 `GALLERY_PHOTOS`。
- 游乐场数量来自 `PLAYGROUND_ITEMS`。

页面将笔记和图集转换为局部统一结构：

```ts
type ActivityItem = {
  id: string;
  kind: "note" | "gallery";
  title: string;
  summary: string;
  date: string;
  href: string;
  image?: string;
};
```

转换与排序只服务此页面，留在 `/now` 路由目录内，不引入全局抽象。默认展示最近八条记录，避免页面退化为另一个完整归档。完整笔记历史仍由 `/archive` 负责，完整图集仍由 `/gallery` 负责。

## 交互与状态

- 每条更新整行可点击，并具有清晰的悬停、键盘焦点和按下反馈。
- 动效仅用于首屏内容的轻微进入和链接反馈，只改变透明度与位移。
- `prefers-reduced-motion` 下取消进入动效，保留即时状态变化。
- 该页面使用构建时可用的本地内容，不设计加载状态。
- 如果笔记和图集均为空，显示简短空状态，并保留游乐场入口。
- 内容缺少可选图片时退化为纯文字记录，不显示破损占位图。

## 路由迁移

- 新增 `/now` 并将其加入站点地图。
- 导航标签改为“近况”，链接指向 `/now`。
- `/guestbook` 使用 Next.js 服务端 `redirect` 跳转到 `/now`，使旧书签继续有效。
- 删除 `GuestbookClient.tsx`，不保留已失去入口的本地存储数据界面。
- 页面元数据改为描述“小屋近期更新”，不再使用留言相关文案。

## 可访问性与性能

- 正文与背景对比度达到 WCAG AA。
- 图集缩略图使用原有标题生成有意义的替代文本，并预留尺寸避免布局偏移。
- 链接具有可见焦点样式，阅读顺序与视觉顺序一致。
- 不依赖颜色单独区分笔记和图集，同时显示文字类型。
- 不增加客户端状态或第三方依赖；交互仅使用链接和 CSS，避免额外水合成本。

## 验证标准

1. `/now` 在无 JavaScript 客户端状态的情况下展示最新笔记和图集，顺序严格按日期倒序。
2. 更新流最多展示八条记录，笔记和图集链接分别到达正确目标。
3. `/guestbook` 能跳转至 `/now`，导航和站点地图不再把留言板作为主栏目。
4. 页面在 `375px`、`768px`、`1024px` 和宽屏下无横向溢出，交互目标满足触控尺寸。
5. 浅色、深色、键盘焦点和减少动态效果模式均保持可用。
6. `npm run lint`、`npm run build` 与 `git diff --check` 全部通过。
7. 本地启动后访问 `/now` 返回成功页面，访问 `/guestbook` 得到正确跳转。
